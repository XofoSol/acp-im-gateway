# v1.2 — kill the approval spam, keep the money gate

Problem: in practice almost every shell call still asks. The user counted ~20 taps for one small
task ("the approvals kill the conversation"). Two causes: compound commands (`cd X && pytest -q`)
and interpreter paths (`./.venv/bin/python -m pytest`) do not match the harmless list, so everything
falls through to `ask`.

Fix, three parts.

## 1. Per-chat posture command

- `/aprobar preguntar` — current behaviour (default).
- `/aprobar auto` — this chat approves everything **except** what matches `always_ask`.
- Persisted per chat in the binding, shown in `/status`, applied immediately.

## 2. The agent must stay in `ask`; the gateway is the only gatekeeper

Critical: do NOT loosen the agent's own `tool_approval` posture to auto as a way to stop the prompts.
If the agent stops sending permission requests, our `always_ask` money gate never sees them and
money can be spent silently. Keep the agent asking, and let the gateway answer: silent for
`auto_allow`, tap for `always_ask`, and for everything else the chat posture decides. Add a test that
pins this rule so nobody "optimises" it away later.

## 3. Make `auto_allow` actually useful

- Split a command line on `&&`, `||`, `;`, `|` and require **every** segment to be harmless; any
  `always_ask` segment forces the tap no matter what else is in the line.
- Normalise interpreter paths: `./.venv/bin/python -m pytest`, `python3 -m pytest`, `pytest -q` are
  the same harmless thing; allow leading env assignments and harmless prefixes (`cd`, `export`,
  `echo`, `true`, `time`, `nice`, `env VAR=x`).
- Harmless means read-only: `git status|diff|log|show|branch|remote`, `ls`, `cat`, `head`, `tail`,
  `grep`, `rg`, `find`, `pwd`, `wc`, `pytest`, `python -m pytest`, `git rev-parse|ls-files`.
- Anything not matched — including `python -c "..."`, arbitrary scripts, network calls — keeps
  asking. Do not widen this beyond read-only.

Tests: compound innocuous line is silent, the same line with one dangerous segment taps, normalised
interpreter paths are silent, `python -c` asks, `/aprobar auto` silences the unknown but still taps
for `always_ask`, and the agent posture stays `ask` in every case. Then run `pytest -q`, commit,
push to origin main.
